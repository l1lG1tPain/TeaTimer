# ☕ TeaTimer — Помощник заварки китайского чая

Простое и элегантное веб-приложение для помощи в заварке гунфу-ча. Выбирайте сорт, настраивайте крепость и получайте автоматические рекомендации по времени проливов.

---

## 🎯 Возможности

✅ **32 сорта китайского чая** (9 категорий)  
✅ **Интеллектуальный таймер** с визуализацией и звуком  
✅ **Кастомные сценарии** заварки  
✅ **История всех чаепитий** с рейтингами  
✅ **Светлая и тёмная тема**  
✅ **Полностью офлайн** (PWA)  
✅ **Никаких внешних зависимостей** (vanilla JS)

## 🚀 Быстрый старт

### Запуск локально

1. **Откройте файл** в браузере:
   ```bash
   # Windows
   start index.html
   
   # macOS
   open index.html
   
   # Linux
   xdg-open index.html
   ```

2. **Или запустите простой HTTP сервер:**
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js
   npx http-server
   ```
   Затем откройте: `http://localhost:8000`

### Установка как приложение

1. Откройте приложение в браузере (Chrome, Edge, Firefox)
2. Нажмите на адресную строку → "Установить приложение" / "Install app"
3. Приложение установится на ваше устройство 📱

## 💡 Первые шаги

### Главный экран
1. Нажмите **"Заварить"** → выберите чай из каталога
2. Настройте **крепость** (лёгкая/средняя/крепкая)
3. Выберите **количество проливов** (1-20)
4. Нажмите **"Начать"** → запустится таймер

### Таймер
- Вверху: обратный отсчёт в MM:SS
- Посередине: номер пролива (4 из 9)
- Снизу: кнопка **"Слил"** → переход к следующему

### История
- Все сессии сортированы по дате
- Рейтинги и заметки к каждой
- Статистика за неделю/месяц

## 🎨 Дизайн и тема

Приложение автоматически выбирает тему по системным настройкам:
- **Светлая** (день) — тёплый кремовый фон
- **Тёмная** (ночь) — тёмный шоколадный фон

Переключить вручную можно в **Настройках → Вид**

**Светлая тема:**
- Фон: `#FDF8EB` (кремовый)
- Акцент: `#2E6B2C` (зелёный)
- Таймер: `#C8801C` (янтарный)

**Тёмная тема:**
- Фон: `#1F1A10` (шоколадный)
- Акцент: `#35792F` (светло-зелёный)
- Таймер: `#E8A93F` (светлый янтарь)

## 💾 Где хранятся данные

**Все данные хранятся локально на вашем устройстве:**

- **IndexedDB** (браузерная БД)
  - Сессии (история чаепитий)
  - Настройки (тема, звук и т.д.)
  - Избранные чаи
  - Кастомные чаи
  - Сохранённые сценарии

Увидеть можно в DevTools:
```
F12 → Application → Storage → IndexedDB → TeaTimerDB
```

## 🔊 Звук и вибрация

### Гонг при готовности
- **Встроенный звук:** кодирован в base64 в HTML
- **Включить/выключить:** Настройки → Сигнал → Звук

### Вибрация
- **Включить/выключить:** Настройки → Сигнал → Вибрация
- **Работает на:** мобильных устройствах, планшетах

### "Не гасить экран"
- **Что делает:** держит экран включённым во время таймера
- **Включить:** Настройки → Сигнал → Не гасить экран
- **Экономит батарею:** выключается после завершения сессии

## 🐛 Типичные проблемы

### Приложение не загружает чаи
1. Откройте **DevTools** (F12)
2. Перейдите на вкладку **Network**
3. Убедитесь, что `teas.json` загружается (статус 200)
4. Если нет — проверьте адрес файла

### IndexedDB не создаётся
```javascript
// В консоли DevTools выполните:
localStorage.clear()
sessionStorage.clear()
```
Затем обновите страницу

### Таймер не срабатывает
1. Проверьте консоль на ошибки (F12 → Console)
2. Убедитесь, что `sound_enabled: true` в настройках
3. Проверьте громкость браузера/устройства

### Тёмная тема не работает
1. Проверьте системные настройки (ОС должна быть в тёмном режиме)
2. Или установите вручную: Настройки → Вид → Тёмная

## 🛠️ Разработка

### Добавить новый экран

```javascript
// 1. Добавить в ROOT_SCREENS:
const ROOT_SCREENS = ['home', 'catalog', 'my-new-screen']

// 2. Создать функцию рендеринга:
function renderMyNewScreen() {
  const screen = document.getElementById('app')
  screen.innerHTML = `<div class="screen">...</div>`
}

// 3. Добавить обработку в navigate():
function navigate(screen, params = {}) {
  if (screen === 'my-new-screen') renderMyNewScreen()
  // ...
}
```

### Добавить CSS переменную

```css
/* В styles.css */
:root {
  --my-color: #123456;  /* Light */
}

@media (prefers-color-scheme: dark) {
  :root {
    --my-color: #abcdef;  /* Dark */
  }
}
```

### Работать с БД

```javascript
// Сохранить
await db.setSetting('my_key', value)

// Прочитать
const value = await db.getSetting('my_key')

// Удалить
await db.deleteSetting('my_key')
```
